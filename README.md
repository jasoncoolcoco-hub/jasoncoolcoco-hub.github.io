# Jason Li — Personal Website

V0.1 is a React + Vite personal website built around the Home chapter. The
remaining Footprints, Lab, and Thanks chapters are represented in the content
model and navigation but are intentionally not implemented yet.

## Local development

```sh
npm install
npm run dev
```

Open the local address printed by Vite (normally `http://localhost:5173/`).

## Production build

```sh
npm run build
npm run preview
```

The Vite base remains `/` for the custom-domain GitHub Pages setup. The existing
`CNAME` must be preserved.

See `DESIGN.md` for visual and asset rules and `AGENTS.md` for repository safety
constraints.
